にほんご おしゃべりゲーム

Genki I　L1–12　／　オンラインクラス用
デザイン
「カードをひく」をおして、場面に合う文を日本語で言いましょう。
ひいたカード
進め方（先生用）
  • 最初の数回は宿題の「きっかけ表」を見てOK。慣れたら見せない。
  • 簡単な答えでも直さず、「もう少し詳しく言える？」と聞く。
  • 言えたら「もう一度」で同じカードを別の言い方で。
  • 詰まったら文法名は言わず、「これはお願い？ それとも許可？」と役割を聞き返す。

生徒さんが自分のことを3文で言います。1つだけうそ。先生が質問しながら、どれがうそか当てます。

「お題をひく」をおして、そのお題で3文考えましょう。
進め方（先生用）
  • 最初は先生が見本を見せる。生徒さんは、うそを当てる側から。
  • 当てるとき、「どうして？」「いつ行ったの？」「何をしに？」と質問する。理由や目的を言うので、自然に文法が増える。
  • うそをうまくつけたら、先生が「だまされた！」と大げさに悔しがる。
  • 直さずに聞き返して、ひと言足してもらう。

先生が「困った人」になります。生徒さんは助けたり、アドバイスしたりします。

「困ったことをひく」をおすと、先生が困ります。
進め方（先生用）
  • 先生は、書いてあるせりふをそのまま、困った声で言う。
  • 生徒さんがひと言で終わったら、「もう少し助けて」「ほかに何かある？」と続ける。
  • 1枚で、ましょうか → たほうがいい のように、2つ言えたらOK。

ふつうに先生と話して、文法を自然に使えたらそのマスをクリック。1列そろえばビンゴ。全部うめたらボーナス！（ビンゴ2はビンゴ1のあと）

先生の質問リスト（文法名は言わずに聞く）
  • 〜ので／から ← 「どうして？」
  • 〜つもりです ← 「今度の休みは何をするの？」
  • 〜たことがある ← 「前にしたことある？」
  • 〜に行きます ← 「何をしに行くの？」
  • 〜と思います ← 「明日の天気はどうなると思う？」
  • 〜なければいけません ← 「行く前にしないといけないことは？」
  • 〜ましょうか ← （先生が困ったふりをして）手伝いを申し出てもらう
